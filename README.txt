The purpose of this project is to create a social media site similar to discord which allows users to create threads, access the threads, register, and login with a new account. 


2.
A. What problem does your app solve or what purpose does it serve?
This app will allow users to form communities with similar interests or chat channels for members of a group or organization to gather and talk. 

B. Who is the intended user?
Anyone interested in using social media website to express themselves, share ideas, and discuss shared interests.

C. What actions will users be able to perform?
Sign up, Add Items, Search, Comment, Post photos, create threads, Add friends, create interest groups. 

The this project will use React and React Components for the webapp. It will be one page will require no loading to separate pages.
